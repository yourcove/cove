# Segments and compilations

Segments let you describe meaningful spans inside a media item. Virtual compilations let you reuse those spans without duplicating the original file.

## Segments

A segment can represent a sub-scene, highlight, chapter, detected range, manual selection, or extension-generated span. Segments can be reviewed, refined, and connected back to their source media.

## Resolved spans

Resolved spans make overlapping or derived ranges easier to reason about. Cove can show where spans came from and how they combine, so automated detection does not hide the source context.

## Virtual compilations

Virtual compilations point at existing media and spans. They are useful when you want a playlist-like result without producing duplicate files for every combination.
