# Organizing your library

Cove is built around real organization workflows, not only title lists. Most libraries start simple and become more structured over time; Cove supports that gradual path.

## Core objects

- **Scenes, images, galleries, audio, and text** are first-class media records.
- **Performers and studios** give people and sources stable identities across the library.
- **Tags and tag groups** describe content, style, state, and personal organization choices.
- **Groups** collect media intentionally, while dynamic groups collect media from rules and activity.

## Day-to-day workflow

1. Add media through library scans, URL import, downloader workflows, or manual edits.
2. Attach the broad metadata that helps you find it later.
3. Use saved filters and dynamic groups for recurring views.
4. Review provenance when automated metadata changed something important.

You do not need to fully classify everything on day one. Cove is designed so rough organization can become precise organization without starting over.
