# Search and filters

Cove search is built for libraries where exact filename memory is not enough.

## What you can search

Use search and filters across titles, paths, media types, tags, tag groups, performers, studios, groups, watch state, generated media state, and other metadata Cove tracks.

## Saved filters

Saved filters turn recurring searches into one-click views. They are useful for cleanup queues, unwatched media, missing metadata, favorite studios, specific tag combinations, and review workflows.

## Tips

- Use broad filters to narrow the collection, then search inside the result.
- Save filters you use more than once.
- Combine search with dynamic groups for views that stay updated automatically.
