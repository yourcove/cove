# Dynamic groups

Dynamic groups collect media from rules, activity, and saved intent. They stay current as the library changes.

## Built-in workflows

- **Save for Later** keeps a deliberate queue without creating a permanent collection.
- **Watch history** helps you return to recently viewed media and understand activity over time.
- **Continue Watching** highlights unfinished items and ongoing sessions.
- **Saved filters** can behave like smart groups when you use them as recurring library views.

## When to use a normal group

Use a normal group when you are intentionally curating a stable collection. Use a dynamic group when membership should update automatically based on rules or activity.
