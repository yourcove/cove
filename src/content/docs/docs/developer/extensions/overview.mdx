# Extension overview

Cove's extension system lets add-ons feel like part of the application instead of a separate sidecar.

Extensions can contribute:

- UI pages, tabs, slots, dialogs, settings panels, and themes.
- Backend APIs, background jobs, event handlers, and middleware.
- Persistent extension storage, schema/data contributions, and generated artifacts.
- Extension-owned permissions that administrators can review and assign.

## Host boundaries

Extensions run inside Cove's host model. They should request the minimum permissions needed, keep user-facing UI consistent with Cove's design system, and make extension-owned data understandable to administrators.
