# Cove Docs

Cove's documentation starts with two paths:

- **User Docs** cover installation, first scan, organization, search, permissions, backups, upgrades, and troubleshooting.
- **Developer Docs** cover extension architecture, packaging, permissions, API surfaces, and contribution workflows.

## Start here

- [Open User Docs](./user/)
- [Open Developer Docs](./developer/)

If you are deciding whether Cove fits your setup, start with User Docs. If you are building an extension or working on Cove itself, start with Developer Docs.
