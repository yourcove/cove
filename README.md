# Cove Website

Astro + Starlight site for Cove's marketing pages, User Docs, and Developer Docs.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- Planning lives in [WEBSITE_PLAN.md](WEBSITE_PLAN.md).
- The docs side is split into User Docs and Developer Docs.
- GitHub Pages is the initial deployment target.
