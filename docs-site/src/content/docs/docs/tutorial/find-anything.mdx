This tutorial uses two searches to show the difference between finding something anywhere in Cove and narrowing one kind of media. You do not need to change any records.

## Search across the whole library

1. Select **Search all…** in the navigation bar.
2. Enter a title, person, studio, group, or topic you remember.
3. Review the headings in the result panel. Cove keeps videos, galleries, images, groups, audio, text, and other matching record types distinct.
4. Select one result to open it, then use **Back** to return.

The sample library uses `Apollo 11`. One query finds related videos, a gallery, individual images, a group, audio recordings, and text records without requiring the reader to choose a media type first.

## Narrow one list

Global search helps you choose a destination. A list search helps you work within it.

1. Open **Videos**.
2. Enter part of a title, tag, performer, or studio in **Search list**.
3. Check the item count beside the page title. It changes to the number of matching videos.
4. Change the sort field or direction to put the most useful result first.
5. Try **Grid** and **List**. The result set stays the same while its presentation changes.
6. Clear the search to return to the full video list.

Repeat the same exercise on **Images**, **Audios**, **Texts**, or **Galleries**. Each page searches fields meaningful to that record type while keeping the same overall pattern.

## Choose the lightest useful tool

- Use **Search all…** when you do not know which page contains the result.
- Use **Search list** when you know the record type and remember a word or relationship.
- Use **Filter** when you need a rule such as missing metadata, a rating range, a technical property, or several conditions together.
- Use **Saved filters** when that rule describes a view you will revisit.

Search first. Add filters only when the remaining result is still too broad. The [Search and filters guide](../../user/library/search-and-filters/) covers filters, saved views, sorting, and specialized layouts after this first search experience.

You can now retrieve an item without remembering where you first saw it. Continue with [Organize a collection](../organize-a-collection/) to make a small set of related records that is useful to you.
