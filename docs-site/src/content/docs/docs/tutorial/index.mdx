Tutorials teach Cove by leading you through a complete working experience. Follow them in order within a path; use the [Guide](../guides/) when you need instructions for a specific task and the [Reference](../reference/) when you need exact behavior or terminology.

## Use Cove

Start with [Install Cove](../user/getting-started/install/) if Cove is not running yet. Then [scan your first library](../user/getting-started/first-scan/) to connect a media location, run a scan, and verify the records Cove creates.

After that first result, the Guide explains how to [import an existing library](../user/getting-started/import-existing-library/), [organize records](../user/library/organizing/), and [search and filter](../user/library/search-and-filters/).

## Build extensions

Start with [Run Cove locally](../developer/getting-started/local-development/) if you do not already have a development instance. Then [create your first extension](../developer/extensions/create-extension/) to build, package, install, and verify one contribution end to end.

Once that path works, continue with a focused tutorial:

- [Create a scraper](../developer/extensions/create-scraper/)
- [Create a downloader](../developer/extensions/create-downloader/)

The Guide covers the underlying [extension architecture](../developer/extensions/overview/), while Reference defines [extensions](../reference/extensions/), [extension points](../reference/extension-points/), and [manifests](../reference/manifests/).
