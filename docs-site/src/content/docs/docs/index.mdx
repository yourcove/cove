Cove’s documentation is split on purpose:

- **User docs** explain how to install Cove, scan media, organize the library, search it, secure it, and keep it running.
- **Reference** describes Cove records, fields, interface surfaces, options, and terminology for precise lookup.
- **Developer docs** explain how to run Cove locally, understand the host model, and build extensions, scrapers, and downloaders.

## Choose your path

- **Use Cove:** [Install Cove](./user/getting-started/install/), then [Scan your first library](./user/getting-started/first-scan/). The [User guide](./user/) also covers existing installations and everyday library management.
- **Look something up:** Open the [Reference](./reference/) for exact product behavior, starting with [Videos](./reference/videos/) and [Terminology](./terminology/).
- **Build on Cove:** [Run Cove locally](./developer/getting-started/local-development/), then [Create your first extension](./developer/extensions/create-extension/). The [Developer guide](./developer/) maps the complete development and reference paths.

If you are deciding whether Cove fits your setup, start with the user path. If you are changing Cove or building on top of it, start with the developer path.
