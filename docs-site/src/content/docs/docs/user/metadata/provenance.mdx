Provenance is Cove's record of where metadata came from and how it changed.

## Why it matters

Large libraries often combine manual edits, file scans, scrapers, downloaders, AI workflows, and extensions. Provenance keeps those changes understandable instead of turning the library into a pile of unexplained values.

## What to review

- Which source created or changed a field.
- Whether a value came from a scan, provider, extension, or manual edit.
- When important metadata changed.
- Which generated artifacts or extension outputs influenced the current view.

Use provenance when you need to trust a value, undo a mistake, or understand why an item appears in a search or group.
