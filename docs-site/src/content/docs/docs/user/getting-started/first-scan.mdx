Your first scan gives Cove the file inventory it needs to build the rest of the library experience.

## Before you scan

- Put media in folders Cove can read reliably.
- Decide whether the folder should be watched continuously or scanned manually.
- Make sure the Cove service account has read access to the media and write access to any configured generated-media location.

## What Cove creates

During scanning, Cove records files, media type, paths, basic metadata, generated previews, and processing state. Later workflows can add tags, performers, studios, groups, segments, provenance, and extension-owned data without changing the original files.

## After the scan

Start with broad organization first: fix obvious duplicates, add high-value tags, review missing metadata, and create saved filters for recurring cleanup work.
