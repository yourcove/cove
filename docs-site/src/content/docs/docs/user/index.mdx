## What lives in Cove

Cove stores more than file paths. A real library can include videos, images, galleries, audio, text, tags, tag groups, performers, studios, groups, segments, watch-state workflows, user accounts, permissions, generated media, and metadata history. The rest of these docs explain how those pieces fit together in practice.

For a guided first experience, [scan your first library](./getting-started/first-scan/). When you need field-by-field lookup instead of a procedure, use the [Videos reference](../reference/videos/) and the broader [Reference](../reference/).
