Cove's primary documentation is now grouped by reader goal:

- [Get Started](../get-started/) connects installation, first-run setup, and the introductory learning path.
- [User Guide](../user/) covers everyday use and administration.
- [Developer](../developer/) covers local development, extension building, architecture, and APIs.
- [Reference](../reference/) provides exact lookup for Cove's records, contracts, and terminology.

Individual pages still use focused tutorial, how-to, explanation, or reference writing styles. Those page types guide authors without making readers choose a documentation genre before they know where their task belongs.
