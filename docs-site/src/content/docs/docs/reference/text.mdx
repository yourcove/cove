title: Text
description: Reference for Cove text document records.

Text is a primary media record for written content stored or indexed by Cove. It lets written material participate in the same library organization and access model as audiovisual media.

## Record model

A text record has its own identity, title and descriptive metadata, created and updated timestamps, and organization state. It can relate to tags, performers, studios, groups, URLs, and custom fields where those capabilities are available.

The stored or indexed body is content rather than a substitute for the record's title, relationships, and provenance. Source location, format, and size are file concerns when a file backs the record.

## Library behavior

Text records can appear in search, filters, groups, and permission rules alongside other supported entities. Playback-only concepts such as duration, resume position, and timeline segments do not apply unless an extension introduces a separate capability.

Installed extensions can add importers, metadata, actions, fields, or presentation. Those contributions do not change the distinction between the text record and its source.
