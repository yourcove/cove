This path takes you from choosing where Cove runs to a small, organized library you can browse and search. Follow it in order for a new installation, or join at the step that matches an existing Cove library.

## 1. Install Cove

Start with [Choose an installation](../user/getting-started/install/) and select one of the supported paths:

- [Windows x64](../user/getting-started/install-windows/)
- [macOS on Apple silicon](../user/getting-started/install-macos/)
- [Linux x64](../user/getting-started/install-linux/)
- [Docker with Linux containers on `amd64` or `arm64`](../user/getting-started/install-docker/)

Each page ends when Cove is running and the setup wizard appears in your browser.

## 2. Complete first-run setup

[Complete first-run setup](../user/getting-started/first-run-setup/) explains the three choices in the shared wizard:

- Start fresh with media paths Cove can scan.
- Import an existing Stash library.
- Restore a Cove database and optional configuration backup.

Fresh libraries continue to the first scan. A populated import or restore can continue directly to the library tour.

## 3. Learn the essentials

1. [Scan your first library](../user/getting-started/first-scan/) with one representative folder and verify the result.
2. [Explore your library](../tutorial/explore-your-library/) through the home page, a detail page, and a connected record.
3. [Find anything](../tutorial/find-anything/) with global search and the controls on a media list.
4. [Organize a collection](../tutorial/organize-a-collection/) by editing useful metadata and bringing related items together.

When this path is complete, use the [User Guide](../user/) for day-to-day tasks, [Developer](../developer/) when you want to change Cove or build an extension, and [Reference](../reference/) for exact product behavior.
